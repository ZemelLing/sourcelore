# SourceLore

面向程序员的独立 Lore 桌面客户端，借鉴 SourceGit 的布局与交互。
Windows x64 首发，.NET 10、Avalonia 12、编译绑定、NativeAOT。

代码工作流功能已实现并通过受控服务器的 NativeAOT 端到端检查。当前发行包为验收候选版，
受保护浏览器认证、外部服务器连接及干净 Windows 系统验收仍待补充，不能视为完整首版已验收。
