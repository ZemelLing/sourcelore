# Tasks

依据 `proposal.md`、`design.md` 和本变更的七个 capability 规格执行。以下均为待实施任务，不表示已编译、已测试或已发布。第 3 组是前置发布验证里程碑，通过后继续完成其余首版功能。

## 1. 工程基础与可重复的 Windows 发行

- [x] 1.1 建立 `SourceLore.App`、`SourceLore.Core`、`SourceLore.Infrastructure.Lore` 及对应测试项目，配置 .NET 10 和单向依赖；通过解决方案构建验证，Core 不引用 UI 或 SDK。
- [x] 1.2 固定 Avalonia 12、LoreVcs、`win-x64` 原生运行包及兼容文本控件的版本，建立集中包版本和锁定还原；验证重复还原使用相同依赖，记录所选版本与原生库来源。
- [x] 1.3 配置编译绑定、类型化数据模板、显式视图/服务注册和 AOT 分析，建立 `win-x64` NativeAOT 发布入口；验证错误绑定在构建期报错，基础窗口能从发布目录启动且没有未解释的裁剪/AOT 诊断。
- [x] 1.4 编写构建与目录发行说明，列明实际 Windows AOT 工具链、发布命令、所含原生库及许可；按说明在构建机执行一次发布并核对产物清单。

## 2. Lore 原生边界与操作调度

- [x] 2.1 针对固定 SDK 建立能力映射记录，逐项确认根目录识别、状态/dirty、暂存/取消暂存、提交、内容/diff、历史分页、认证、克隆、推送/同步、冲突查询/解决/中止及分支 API；以可编译调用和参数/事件清单验证，明确读写性质与版本差异。
- [x] 2.2 实现原生版本/加载诊断、应用级生命周期和参数/回调句柄管理；用真实 SDK 验证重复操作、错误返回及关闭释放，确认回调外只持有复制后的托管数据。
- [x] 2.3 建立工作目录会话、类型化后端契约、操作结果和串行调度器；通过可控延迟/失败用例验证同目录写操作及元数据更新互斥、不同会话不串状态。
- [x] 2.4 实现查询代次、进度合并与 UI 派发，保留原生调用到真正完成；验证迟到结果被丢弃、完成事件不丢失，且失效查询不会造成提前释放或窗口冻结。
- [x] 2.5 实现未完成操作标记、结果核对和日志脱敏，记录 SDK 生命周期与重试约定；通过模拟进程重启和结果不确定用例确认不自动重放写操作，并检查日志/配置无测试令牌。

## 3. 首个 NativeAOT 真实工作流里程碑

- [x] 3.1 建立隔离的临时 Lore 仓库 fixture，通过 SDK 创建初始版本和新增/修改/删除文本样本；验证 fixture 能重复创建与清理，清理范围严格限制在测试目录。
- [x] 3.2 接通最小仓库入口、初始扫描和变更列表；用发布程序打开 fixture，确认真实文件状态、中文/含空格路径和无效目录提示正确。
- [x] 3.3 接通工作文件与当前版本的文本读取/差异及只读控件；在 AOT 发布程序中验证中文、行号、滚动、选择和复制，控件不兼容时按设计替换渲染实现并通过同一用例。
- [x] 3.4 实现文件暂存、取消暂存与本地提交的最小适配，并通过 AOT 可执行测试入口验证“暂存后再编辑、只提交已选文件、保留未选修改”和失败错误路径。
- [x] 3.5 执行完整目录发行包的加载、状态、差异、提交、重复回调和退出检查，产出版本与诊断记录；确认没有未处理的 AOT 问题后才进入后续功能组，普通 JIT 测试结果不能替代此检查。

## 4. 工作目录会话、克隆与认证

- [x] 4.3 实现远端克隆界面及目标目录校验，接入进度、错误与成功打开；在受控服务器验证正常克隆、非空目标拒绝和失败残留目录提示。
- [ ] 4.4 编写连接、最近记录和认证恢复说明；按文档从无 CLI 依赖的客户端完成连接流程，并覆盖普通目录/Git 目录拒绝、网络不可达和登录取消场景。

- [x] 5.1 实现文件监控去抖、增量 dirty 通知、操作后事件合并及手动/恢复扫描；通过外部编辑与监控溢出用例验证新增、修改、删除、忽略项和恢复原文件后的状态准确性。
- [x] 5.2 完成变更列表的 dirty/staged 独立展示、文件级勾选和批量部分失败处理；通过真实暂存/取消暂存和部分路径失败用例验证界面与后端状态一致且不改写未提交内容。
- [x] 5.3 完成提交说明、输入校验、提交结果、草稿和状态刷新；验证空说明、空提交、冲突阻止、只提交选定文件、不隐含推送以及失败/结果待核实时的草稿保留。
- [x] 5.4 补充工作区状态与暂存语义说明并进行交互检查；验证扫描未完成或失败不会显示为干净，用户能理解已暂存文件继续编辑后提交采用最新内容。

- [x] 6.1 完成统一/并排差异模型和视图切换；通过新增、删除、空文件、中文、UTF-8/UTF-16 BOM、CRLF/LF 与末尾换行 fixtures 验证相同差异语义，预览前后原文件字节一致。
- [x] 6.2 实现有界读取、大小/行数/单行限制、编码失败/二进制提示和外部打开；通过边界样本、超限样本及外部工具缺失用例验证无界加载被阻止，文档说明预览限制。
- [x] 6.3 实现固定起点的历史分页和刷新提示；用多页历史及分页期间新增提交用例验证无重复/遗漏，查询错误和离线内容缺失不显示为空历史。

- [x] 6.5 实现基于已核实远端锚点的未推送状态与核实时间，补充历史/差异使用说明；验证离线本地提交、过期远端信息及未知数量不被误报为零或已推送。
