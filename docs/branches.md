# 基础分支操作

打开工作目录后，在分支页读取本地分支。当前标识来自实际工作目录状态。
列表是已缓存的本地信息，时间仅表示本地读取时间，不证明远端状态最新。
读取失败时保留已知列表并标记过期，不把失败当成分支已删除。

“从当前版本创建并切换”填写新名称后，先扫描核对本地工作，再从提示的当前版本
创建并立即切换。创建会改变当前分支；没有历史版本起点，也没有仅创建不切换选项。
历史版本创建留待后续扩展。名称和重复名称由固定 Lore SDK 校验。

例如，先在干净的 main 上创建 feature-code，当前版本保持不变，当前分支变为
feature-code。提交代码后，在列表中选择 main 并执行“切换到所选已有分支”，
工作文件恢复 main 的版本；再切回 feature-code 可以继续该分支的工作。
无需 Git 或 Lore CLI。

有 dirty 文件、未跟踪内容、暂存选择或未完成合并时安全拒绝创建/切换；先自行
处理或提交本地工作。客户端不提供强制重置，也不自动保存或删除用户内容。
错误或完成结果不明确时重新读取真实分支/版本，保留核对标记；不会按请求名称
乐观更新当前标识或自动重放。检查实际状态并明确确认核对后才能再操作。

历史页可以从分支选择框选择已缓存的分支，然后显式加载/刷新历史。
选择分支作为历史起点不改变当前工作分支；只有分支页的切换按钮执行切换。
