# 文本差异

工作区选择文件后，左侧为当前版本、右侧为本次读取的工作文件。标题显示完整版本与
路径，编码和换行方式单独展示。新增/删除的一侧显示“不存在”，与实际存在的空文件区分。
历史比较使用相同的内容读取与差异模型。

“并排差异”只切换呈现，不重新查询或改写文件。统一视图标注左/右源行号；并排视图
标注各侧源行号，同一改动块的删除/新增行并排对齐，较短侧用空行占位。
删除行红色、新增行绿色。改动行的
`⟦CRLF⟧`、`⟦LF⟧`、`⟦CR⟧` 和 `⟦无末尾换行⟧` 明确标识换行变化；编码 BOM
变化通过两侧编码标识显示。选择复制的是展示文本，包含标记，不是原始文件导出。

每侧最多 8 MiB、100,000 个文本行、单行 100,000 个 UTF-16 字符。恰好位于上限可预览，
末尾换行不生成额外虚构文本行。支持严格 UTF-8（可有 BOM）和带 BOM 的 UTF-16 LE/BE；
非法序列、不支持的编码和含 NUL 的二进制内容拒绝预览，不猜测传统编码、不以截断内容
冒充完整差异。两侧均受限制；版本先检查 SDK 大小，再导出到随机临时目录、严格解码，
结束后删除临时导出。读取期间工作文件变化会报告差异过期，需要重新选择或扫描。

差异按唯一内容行的有序锚点分块，块内 LCS 的总计算预算为 2,000,000 个矩阵单元。
超预算块按完整删除/新增显示并注明原因，仍表达全部字节解码后的文本变化，不截断或
伪造相同内容。两种模式始终共用同一组结果行。

无法预览时，可点击“使用外部编辑器打开工作文件”，通过 Windows 记事本查看/编辑
实际工作文件。已删除文件不能打开；记事本缺失或启动失败会显示错误并保留草稿与文件。
外部打开是明确操作，不会因预览失败自动启动工具。历史页提供左/右只读版本快照的
外部打开入口：SDK 导出到随机临时目录，设置只读属性，客户端正常退出时清理。
外部工具仍占用快照时保留文件，不阻止客户端正常关闭。版本外部导出上限为 512 MiB，
不在内存解码；超过上限明确拒绝。首版不提供资产专用预览。

比较默认读取本地缓存，内容缺失不会显示成空文件。需联网时明确点击工作区的“从远端
读取版本内容”或历史页的“从远端读取所选历史内容”；它使用相同的两侧大小/解码限制，
只读取并缓存内容，不切换分支或改写工作文件。克隆/同步开启 SDK 文件片段缓存，供后续
离线比较；缓存仍可能被 SDK 淘汰，不能保证所有历史内容始终可离线访问。
