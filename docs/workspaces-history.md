# 工作目录与本地历史

输入工作目录路径并打开。子目录由 Lore 验证并解析到所属根；无效目录会报错，
不会初始化或转换。成功打开才保存最近记录，配置只含根路径和显示名称，不含远端地址或凭据。
最近记录写入用户的 LocalAppData/SourceLore；移除记录只改变列表，不删除磁盘内容。

切换目录时按原生实例身份恢复提交草稿、文件选择及页面位置。路径别名共享会话，
同一远端的不同克隆保持独立。失效记录可以移除，打开失败不会替换当前有效会话。

克隆入口分别填写远端地址和新的本地目标目录。目标必须不存在或为空；失败后显示并
保留残留路径，检查内容后再决定新目标。克隆成功才打开并加入最近记录。

历史页选择已缓存分支后点击加载/刷新，默认每页最多 100 条。分页固定所选分支的已知最新版本作为起点，通过 SDK
读取版本身份、元数据和全部父版本，以主父优先的图遍历顺序展开；不会提前读取整条历史。
每页最多 100 次版本查询。所有父链均保留，并对共同祖先去重；失败时不推进游标。
刷新失败或离线缺失内容保留已有列表，错误包含缺失版本身份。新提交产生后提示刷新，
继续翻页保持旧起点，显式刷新才重建。作者/时间缺失不会猜测。

选择版本可滚动查看完整说明、身份、全部父版本及受影响文件。默认以主父比较，可改选
其他父版本或已加载的任意历史版本作为左侧。文件列表随左侧选择更新，最多 10,000 项；
超限显示错误，可输入相对路径进行同路径比较。初始无父版本按不存在的空侧处理。
目录不当作文本读取；快速切换版本、父版本、文件或工作目录时，旧结果不能覆盖新来源。
统一/并排预览、缓存缺失重试与外部只读快照的说明见 [文本差异](text-diff.md)。
